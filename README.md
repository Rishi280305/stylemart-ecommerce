# StyleMart 🛍️

A responsive e-commerce frontend website built using HTML5, CSS3, and Vanilla JavaScript.

## 🚀 Live Demo

[Visit StyleMart](https://rishi280305.github.io/stylemart-ecommerce/)

## ✨ Features

- Product listing from Fake Store API
- Product search
- Category filtering
- Product sorting
- Product details page
- Add to cart
- Increase/decrease product quantity
- Remove products from cart
- Cart data stored using LocalStorage
- Checkout form with validation
- Order simulation
- Toast notifications
- Loading, error, and empty states
- Responsive design for mobile and desktop

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (ES6+)
- DOM Manipulation
- Events
- Fetch API
- REST API
- LocalStorage
